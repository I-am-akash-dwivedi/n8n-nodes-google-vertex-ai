# Changelog

All notable changes to this project are documented here. This project follows
[Semantic Versioning](https://semver.org/).

## 0.1.0

Initial release.

- **Text** — Message a Model (Gemini).
- **Image** — Analyze, Generate, and Edit (Gemini "Nano Banana" image models) with binary image output.
- **Document** — Analyze.
- **Audio** — Analyze and Transcribe.
- **Video** — Analyze, plus a Veo flow: Generate (long-running), Get Status, and Download (inline base64 → binary).
- Custom **Google Vertex AI API** service-account credential (Region, Project ID, Service Account Email, Private Key) with a connection test.
